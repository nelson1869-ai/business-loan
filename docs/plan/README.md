# Lending Nelson Learning Plan

This folder contains the project progress as small, student-friendly phases.

Only completed and verified work is documented. New phases should be added manually
after their work has been finished and checked.

## Available phases

| Phase | Topic | Status |

| [Phase 1](phase-1/README.md) | Project foundation and development setup | Completed |

## Progress rule

- `[x]` means completed and verified.
- `[ ]` means not completed.
- Do not mark a lesson complete before performing and checking the work.
- Add each future phase in its own folder, such as `phase-2/`.
