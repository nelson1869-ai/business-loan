4. Architectural Component Responsibilities

Component Responsibilities Summary
Layer Component Directory Path Primary Technical Responsibility
PostgreSQL Models backend/app/models/ Relational entities (`users`, `borrowers`, `loans`, `loan_installments`, `payments`, `audit_logs`) with foreign keys and unique indexes.
FastAPI Routers backend/app/routers/ Exposes REST API endpoints, validates HTTP headers, manages status codes (`200`, `201`, `401`), returns Pydantic responses.
Business Services backend/app/services/ Implements domain logic (reducing balance amortization, bcrypt hashing, JWT issuance, PII audit redaction).
Dio Network Client lib/core/network/ Manages HTTP requests from mobile app, handles JWT headers, auto-retries failed calls on 401 via `JwtInterceptor`.
