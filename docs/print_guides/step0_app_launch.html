ELI5 Health Check: When the app or Postman starts, it sends a quick HTTP GET to `/health`. If the server responds `{"status": "ok"}`, we know the backend service is up and connected!

Layer 2: FastAPI App Factory & Health Endpoint

FastAPI App Factory — backend/app/main.py
Main App Entrypoint — main.py
def create_app() -> FastAPI:
    application = FastAPI(title="Lending Nelson API", version="1.0.0")
    
    # Enable CORS for Flutter web & local development clients
    application.add_middleware(
        CORSMiddleware, allow_origins=["*"], allow_credentials=True,
        allow_methods=["*"], allow_headers=["*"]
    )

    @application.get("/health", tags=["Health"])
    async def health_check() -> dict[str, str]:
        return {"status": "ok"}

    return application

Layer 5: GoRouter Initial Path & Session Guard

GoRouter Navigation Guard — lib/app/app_router.dart
Router Setup — app_router.dart
final routerProvider = Provider<GoRouter>((ref) {
  return GoRouter(
    initialLocation: '/',
    routes: [
      GoRoute(path: '/', builder: (context, state) => const SplashScreen()),
      GoRoute(path: '/login', builder: (context, state) => const LoginScreen()),
      GoRoute(path: '/dashboard', builder: (context, state) => const DashboardPage()),
    ],
  );
});
ELI5 Router Guard: When the app launches, GoRouter opens the `/` SplashScreen. The splash screen reads `FlutterSecureStorage`. If a valid token exists, it routes to `/dashboard`; otherwise, it routes to `/login`.

Troubleshooting Checklist
Issue / Error Symptom Root Cause Backend / Database Fix
Postman GET /health Timeout Uvicorn server not running or wrong port (default 8000) Run uvicorn app.main:app --reload from backend/ directory.
CORS Policy Blocked in Browser Missing CORSMiddleware in FastAPI main.py Verify allow_origins=["*"] middleware is added in create_app().
SQLAlchemy Async Connection Refused PostgreSQL daemon down or incorrect database_url Check PostgreSQL service status or verify .env database credentials.
